# DEAD ZONE

**プレイURL：https://jadp10015237-ux.github.io/dead-zone-/**

Android Chrome向けの横画面3Dゾンビサバイバル。Three.js / TypeScript / Viteで制作。インストール・ゲーム用アカウント・課金は不要です。

## Androidで遊ぶ手順

1. 上のURLをAndroidのChromeで開きます。ChatGPT内の画面ではなく、Chromeで開いてください。必要ならURLをコピーしてChromeのアドレス欄に貼り付けます。
2. スマートフォンの自動回転を有効にして横向きにします。
3. 「出撃する」を押します。救援まで5分間生き延びるとクリアです。
4. 動作が重い場合はタイトル画面の画質を「省電力」にしてください。音量は端末側でも調整できます。

## 操作

| 操作 | タッチする場所 |
| --- | --- |
| 移動 | 左下の仮想スティック |
| 照準方向を回転 | 右側の空きスペースを左右にスワイプ |
| 射撃 | FIREを長押し |
| リロード | ↻ / RELOAD |
| ダッシュ | » / DASHを長押ししながら移動 |
| 一時停止 | 右上のⅡ |

移動しながら射撃できます。照準方向に近い敵へ軽いエイムアシストがあります。初期装弾数12発、予備48発。緑の＋はHP回復、黄色い箱は弾薬補給です。HPが0になるとゲームオーバー。「最初からやり直す」で再挑戦できます。

- ピストル12発＋予備48発、0.3秒間隔、1.5秒リロード、壁による射線遮断
- 300秒生存、撃破数、時間に応じた出現増加、回復・弾薬ドロップ
- 一時停止、結果画面、再挑戦、横向き案内、画質切り替え
- プログラム生成のモデルと効果音・環境音。外部素材サービス不要
- 静的都市メッシュの結合、ジオメトリ・マテリアル共有、ゾンビ再利用

## 開発者向け

Node.js 22.18以上。`npm install` → `npm test` → `npm run build`。`npm run dev`でローカル起動。本番配信用ファイルはdistに出力されます。`npm run test:browser`にはGoogle Chromeが必要です。通常の公開ビルドにはテスト用フックは含まれません。

mainへのpushでGitHub Actionsがテスト、ビルド、ブラウザ検証、Pages公開を行います。READMEのみの今回の記録更新はCIをスキップしています。

## 通信障害について

このCodex実行環境の通常サンドボックスでは、設定済みプロキシへの接続がEPERMで拒否されました。GitHub接続ツールでコードを登録し、GitHub Actionsの実行環境で依存取得・ビルド・検証・公開に成功しました。以前の障害はゲーム完成・公開の阻害要因ではなくなっています。
